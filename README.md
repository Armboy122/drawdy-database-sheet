# Drawdy Sheet & Table Creator Extension (ตาราง Sheet & เมทริกซ์เปรียบเทียบข้อมูล)

ส่วนเสริม (Extension) สำหรับ **Drawdy Whiteboard** ตามมาตรฐาน Drawdy Driver Protocol (DDP) เพื่อให้คุณสามารถ **กดเพิ่มตาราง / Sheet ลงบนผืนผ้าใบ (Canvas) ได้ทันที** มีคอลัมน์และแถวชัดเจน พร้อมดับเบิลคลิกกรอกข้อมูลเปรียบเทียบประเด็นต่างๆ ได้อย่างง่ายดาย

---

## ✨ ความสามารถเด่น (Key Features)

1. **กดปุ่มแทรกตารางลงบน Canvas ได้ทันที**:
   - มีปุ่มลัดด้านบน: `📊 แทรกตาราง Sheet (Insert Table)`
   - คลิกขวาบนพื้นที่ว่าง: `📊 แทรกตาราง Sheet เปรียบเทียบข้อมูล...`
   - ตารางจะถูกวาดลงตรงหน้าจอ (Viewport Center) ของผู้ใช้โดยอัตโนมัติ ไม่ต้องคอยเลื่อนเมาส์หา
2. **มีเทมเพลตเปรียบเทียบสำเร็จรูปให้เลือก หรือกำหนดเองได้อิสระ**:
   - 📋 **ตารางเปรียบเทียบ 2 ฝั่ง (3 คอลัมน์)**: หัวข้อ | ทางเลือกเดิม (A) | ทางเลือกใหม่ (B)
   - 📊 **ตารางเปรียบเทียบครบวงจร (4 คอลัมน์)**: หัวข้อ/ฟีเจอร์ | ทางเลือก 1 | ทางเลือก 2 | ผลลัพธ์/หมายเหตุ
   - ⚖️ **ตารางข้อดี-ข้อเสีย (Pros & Cons)**: ประเด็นพิจารณา | ข้อดี (Pros) | ข้อเสีย (Cons) | ข้อสรุป
   - 💰 **ตารางราคา & สเปก (Pricing Sheet)**: แพ็กเกจ | ราคา | คุณสมบัติ | ความเหมาะสม
   - ⚙️ **กำหนดเอง (Custom Sheet)**: พิมพ์ชื่อคอลัมน์คั่นด้วยจุลภาค `,` และเลือกจำนวนแถวเริ่มต้น (1 - 15 แถว) ได้ตามใจชอบ
3. **เซลล์ตารางแก้ไขได้ทันทีบน Canvas (Inline Editable Cells)**:
   - แต่ละช่องในตารางเป็น Shape พร้อมข้อความ สามารถดับเบิลคลิกแล้วพิมพ์แก้ไขเปรียบเทียบข้อมูลได้โดยตรง
   - มีการจัดสีแถวสลับ (Zebra striping) และเลือกธีมสีหัวตารางได้ (ฟ้า, เขียวมรกต, ม่วง, ส้มทอง, โหมดมืด)
4. **ปุ่ม ➕ เพิ่มแถว (Add Row)**:
   - มีปุ่มลัด `➕ เพิ่มแถว (Add Row)` บนแถบเครื่องมือ เพื่อต่อขยายตารางเดิมลงมาด้านล่างได้ทันทีโดยไม่ต้องสร้างใหม่

---

## 🚀 วิธีติดตั้งบน Drawdy (Private Extension)
1. ไปที่ [drawdy.io/account/extensions](https://drawdy.io/account/extensions) -> แท็บ **Submit**
2. เลือก **Private**
3. วาง URL: `https://github.com/Armboy122/drawdy-database-sheet`
4. กด **Add extension**
5. เปิดกระดาน Drawdy -> กดไอคอนตัวต่อ 🧩 -> แท็บ **Private** -> กด **Install**
